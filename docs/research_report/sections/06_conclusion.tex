\section{Conclusion}
\label{sec:conclusion}

This section first revisits the motivation for GLASS, then summarises its design and results, and finally identifies the limitations and next steps.

IoT networks produce traffic whose security depends on both individual events and patterns across communicating devices. Machine learning can classify connections from numerical measurements, and deep learning can learn representations of those measurements. GNNs add a way to model communication context, while pretrained language models offer representations of textual event descriptions. Combining these approaches is a reasonable design direction, but it also raises a practical question: does their interaction improve detection beyond the strongest individual component?

This study addressed that question through GLASS (Graph-Language Adaptive Semantic-Structural fusion). GLASS converts aggregated traffic into a directed graph and a corresponding set of templated edge descriptions. A graph attention network learns structural representations, and frozen CySecBERT supplies semantic embeddings. An adaptive gate combines the two views across edges and feature dimensions. The feedback stage adds uncertainty-guided consultation, injecting semantic advice before another graph update and using semantic predictions again at the output. The consultant reads the edge's text; it does not revise its advice in response to the graph model's changing belief.

GLASS was evaluated on NF-UNSW-NB15 and NF-ToN-IoT using pooled five-fold out-of-fold predictions at three training seeds and a fixed fold partition. The comparison included the GNN, prototype semantic, fusion and feedback stages, both prototype and trained-head consultants, the trained head alone, and published detectors re-trained on the same aggregated representation. This design makes it possible to distinguish the performance of the complete configuration from the evidence supporting its individual mechanisms.

The trained-head feedback configuration is separated above the GNN, prototype semantic and fusion stages and the faithful re-trained baselines on both datasets. However, the trained head alone has slightly higher mean macro-F1 on both, and its difference from feedback is not separated. Its stronger standalone predictions support the choice of trained head over the prototype readout, but the complete GLASS feedback design has not established an additional benefit over that consultant. Changing the consultant also changed the consultation percentile, so the difference between feedback configurations cannot be assigned to either change alone.

The mechanism diagnostics reinforce this distinction. With output fusion disabled, neither realistic consultant provides a separated injection gain at the earlier consultation settings tested; the trained head produces a separated loss on NF-ToN-IoT. An oracle supplied with true labels improves through the same channel, showing that useful information can pass through it. Attention injection changes no predicted classes between passes in the tested configurations. Fusion is separated above the prototype semantic model on both datasets, but not above the GNN. It therefore does not establish an improvement over both single-branch stages. These findings show why a more elaborate interaction cannot be assumed to produce a better detector.

The conclusions about GLASS remain within the controlled graph-construction scope defined in Section~\ref{sec:method-graph}: labels help determine the aggregated edges, so the current evaluation does not represent deployment on unlabelled traffic. Training-seed variation is measured at one fold partition, small classes limit interpretation, and the mechanism diagnostic does not use the final consultation settings. The next steps are matched mechanism tests at those settings, broader uncertainty measurement, controls for message passing and the weighted branch split, and evaluation with label-independent traffic aggregation. GLASS establishes a reproducible framework for testing these questions and demonstrates the value of a trained semantic classifier, while leaving the additional value of feedback open.
