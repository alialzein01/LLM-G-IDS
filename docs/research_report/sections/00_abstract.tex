\begin{abstract}
\noindent
A trained classifier on frozen language embeddings provides strong semantic predictions for this intrusion-detection pipeline. Combining that classifier with graph feedback does not establish an improvement over the classifier alone. These are the main findings of this study of structural and semantic information in network traffic.

The pipeline represents IP addresses as nodes and aggregated flows as directed edges. A graph attention network learns from communication structure and edge attributes. A frozen cybersecurity language encoder, CySecBERT, encodes a short templated description of each edge. We compare a GNN model, a semantic prototype model, a fusion model and a feedback model on NF-UNSW-NB15 and NF-ToN-IoT. The feedback model is evaluated with both a prototype consultant and a trained classification head. Scores use pooled out-of-fold predictions at three training seeds and a fixed fold partition. Bootstrap intervals distinguish supported differences from orderings of average scores.

With the trained head, the complete feedback model scores above the GNN, semantic and fusion stages by separated margins on both datasets, but its own consultant has slightly higher mean macro-F1 and their difference is not separated. Tests with output fusion disabled find no separated injection gain from either realistic consultant at the earlier consultation settings tested. On NF-ToN-IoT, trained-head injection produces a separated loss. An oracle supplied with true labels does improve through that channel. The evidence therefore supports the value of the trained semantic classifier, while an added benefit from injection remains unestablished. Fusion alone is not separated from the GNN on either dataset. All findings concern controlled comparisons on label-conditioned graphs; the deployment limitation is explained in Section~\ref{sec:method-graph}.
\end{abstract}

\vspace{1em}
\noindent\textbf{Keywords:} intrusion detection, graph neural networks, edge classification,
structural--semantic fusion, uncertainty-guided feedback, negative results.
